# Python Roadmap: From Fundamentals to Machine Learning

A comprehensive Python learning repository containing theory, personal notes, and practical code examples. This repository covers core Python programming concepts, algorithms, data analysis libraries, and foundational Machine Learning models.

##Repository Structure
Here is an overview of the modules and topics covered in this repository:

* **PYTHON OOP`** – Object-Oriented Programming concepts in Python (Classes, Objects, Inheritance, etc.).
* **ALGORITM PYTHON`** – Implementation of fundamental algorithms and logic exercises (including practical scripts like password crackers).
* **NumpyTutorial`** – Numerical computing with NumPy, covering arrays, mathematical operations, and basic statistics (mean, median, etc.).
* **Matplotlib`** – Data visualization techniques, plotting graphs, and creating charts (such as bar charts).
* **Machine Learning`** – Introductory Machine Learning concepts and predictive modeling (such as multiple regression).

## Getting Started

To run the code examples locally on your machine:

1. **Clone the repository**
   ```bash
     git clone https://github.com/codeferrel/python-roadmap.git
   ```
2. **Navigate to the project directory**
   ```bash
   cd python-roadmap
   ```
3. **Install required dependencies** *(Make sure you have Python installed)*
   ```bash
   pip install numpy matplotlib scikit-learn
   ```
4. **Run any script** inside the specific topic folders using Python or Jupyter Notebook.
